===============================================================================
 lecnote — quick reference
 Record a lecture, get clean pastable notes on the clipboard.
===============================================================================

-------------------------------------------------------------------------------
 ONE-TIME SETUP
-------------------------------------------------------------------------------

  # already installed on this machine — this section is for a fresh one.
  # simplest, anywhere:
  #     pip install git+https://github.com/AASHPAW1015/lecnotes.git
  # from a clone, keeping the venv:
  #     python3 -m venv .venv && .venv/bin/pip install -e .

  # put it on PATH — run this once, from anywhere
  echo 'export PATH="/Users/aashpaw/WORKKKKKK/smth/tool/bin:$PATH"' >> ~/.zshrc
  source ~/.zshrc

  # check it worked
  which lecnote        # -> /Users/aashpaw/WORKKKKKK/smth/tool/bin/lecnote

  Until that is done, every command below still works with the full path:
      /Users/aashpaw/WORKKKKKK/smth/tool/bin/lecnote doctor
  `source ~/.zshrc` only affects the shell you run it in; other open terminal
  tabs need it too, or just open a new tab.

  # check keys, microphone, AND transcription before relying on it
  lecnote doctor
      Speak when it says SPEAK NOW. It prints what Whisper heard, so you can
      confirm Hinglish is coming through. Say something like
      "mera naam hello hai" and check the words come back.


-------------------------------------------------------------------------------
 API KEYS
-------------------------------------------------------------------------------

  Keys are read from BOTH of these; whichever exists wins, env vars beat files:

      ~/.lecnote/.env          works no matter how lecnote was installed
      <project root>/.env      only when running from a clone

  Create one:

      mkdir -p ~/.lecnote
      chmod 700 ~/.lecnote
      printf 'GROQ_API_KEY=gsk_...\n' >> ~/.lecnote/.env
      chmod 600 ~/.lecnote/.env

  GROQ_API_KEY          REQUIRED, always.  https://console.groq.com/keys
  ANTHROPIC_API_KEY     optional — only if you have prepaid API credits.

  Why Groq is not optional:
      Transcription needs a speech-to-text model. NO chat subscription
      includes one — not Claude Pro, not ChatGPT Plus, not Google AI Pro.
      None of those expose an audio endpoint. Groq's free tier is generous
      and covers normal lecture use.

  Never commit either key. `.env` is gitignored; ~/.lecnote/.env is outside
  the repo entirely, which is why it is the better place for it.


-------------------------------------------------------------------------------
 USING A SUBSCRIPTION INSTEAD OF API CREDITS
-------------------------------------------------------------------------------

  The NOTES step (not transcription) can run on a chat subscription you
  already pay for, by driving that vendor's coding CLI in headless mode.

  A Claude Pro/Max plan does NOT fund the Anthropic API — separate billing
  pools. That is why a valid ANTHROPIC_API_KEY can still say
  "credit balance is too low".

  LECNOTE_BACKEND    api    Anthropic API, needs prepaid credits
                     cli    a coding CLI, billed to a subscription
                     auto   (default) API first, falls back to cli

  LECNOTE_CLI        claude   Claude Pro / Max            (default)
                     codex    ChatGPT Plus / Pro
                     gemini   Google AI Pro / free tier

  Set it up:

      # 1. install and sign in ONCE, in a terminal
      #    claude -> https://claude.com/claude-code
      #    codex  -> npm i -g @openai/codex   && codex login
      #    gemini -> npm i -g @google/gemini-cli && gemini

      # 2. point lecnote at it
      printf 'LECNOTE_BACKEND=cli\nLECNOTE_CLI=codex\n' >> ~/.lecnote/.env

  lecnote reuses that browser login and strips any conflicting API key from
  the child process — an API key in the environment would otherwise take
  priority and quietly bill the wrong pool.

  Each CLI's own default model is used; override with LECNOTE_MODEL.

  So: a free Groq key + any ONE of those subscriptions = no per-lecture spend.

  Tested here: claude only. codex and gemini are written to their documented
  headless flags but have not been run. If a vendor changes flags, fix one
  entry in CLI_BACKENDS in lecnote/notes.py.


-------------------------------------------------------------------------------
 EVERYDAY USE
-------------------------------------------------------------------------------

  lecnote                      record now; press Enter to stop
  lecnote run png              same, spelled out, with the mode
  lecnote-notion               same, forces Notion markdown
  lecnote-excalidraw           same, forces an Excalidraw diagram

  lecnote toggle notion        start if idle, stop if recording   <- for hotkeys
  lecnote start                start recording in the background
  lecnote status               is anything recording?
  lecnote stop                 stop, transcribe, write notes, copy

  A notification fires when the notes hit the clipboard, so you do not have to
  watch the terminal. Silence it with LECNOTE_NOTIFY=0.


-------------------------------------------------------------------------------
 SYSTEM AUDIO (YouTube, Zoom, recorded lectures)
-------------------------------------------------------------------------------

  lecnote listen               record what the Mac is PLAYING, not the mic
  lecnote listen png           ...with the format to produce
  lecnote output               toggle output: capture <-> normal
  lecnote output --show        which one am I on right now?
  lecnote audio-setup          check the routing, say what is missing

  After `listen`, everything is the same as a mic recording: same session,
  `lecnote redo <mode>` for other formats, `lecnote sessions` to find it.

  ONE-TIME SETUP
      brew install blackhole-2ch
      sudo killall coreaudiod        # drivers only appear after this
      brew install switchaudio-osx   # for `lecnote output`

      Audio MIDI Setup > + > Create Multi-Output Device
          tick BlackHole 2ch AND your speakers
          primary device = your speakers
          drift correction = on for BlackHole
      Set that Multi-Output Device as the system output.

  WHY THE SPEAKERS MUST BE TICKED
      macOS gives no app the speaker mix, so audio is routed through a
      virtual device instead. If ONLY BlackHole is ticked, it is captured
      but you hear nothing. Ticking both sends it to each.

  THE FAILURE TO KNOW ABOUT
      BlackHole installed but output still on the speakers = a full lecture
      of perfect silence. `listen` warns BEFORE recording, but if you ever
      see that warning, run `lecnote output`.

  VOLUME KEYS
      They stop working while a Multi-Output Device is selected. Core Audio
      limitation, not lecnote. `lecnote output` flips back and remembers the
      real device you were on, so headphones are not swapped for speakers.


-------------------------------------------------------------------------------
 OUTPUT MODES
-------------------------------------------------------------------------------

  notion       markdown: headings, tables, code blocks, checkboxes
  obsidian     same, plus LaTeX, callouts, highlights
  excalidraw   an editable diagram scene  (paste onto the Excalidraw canvas)
  png          a rendered flowchart IMAGE (paste straight into Notion)

  png vs excalidraw: same layout engine, same diagram. Use png when you want
  the picture inside the note. Use excalidraw when you want to edit the shapes.

  The mode is the last word of the command:

    lecnote png
    lecnote toggle excalidraw
    lecnote redo notion


-------------------------------------------------------------------------------
 MULTIPLE FLOWCHARTS FROM ONE LECTURE
-------------------------------------------------------------------------------

  A flowchart is for a PROCEDURE — steps you follow to get an answer. One
  diagram is made per distinct procedure in the transcript.

  Teacher does theory, then calculates an IP range, then calculates a CIDR
  value = TWO procedures = two flowcharts. The theory gets none.

      lecnote redo png          -> notes-png-1.png, notes-png-2.png
      lecnote redo excalidraw   -> one scene, both charts side by side

  Both paste in ONE go:
      2+ PNGs   go on the clipboard as FILES (the only way macOS pastes
                several images at once). Notion uploads them all.
      1 PNG     goes on as an IMAGE, so it pastes as a picture as before.

  Images are 128-colour PNGs. Flowcharts are flat fills and text, so this
  looks identical to full colour at roughly half the size.


-------------------------------------------------------------------------------
 WORKING FROM FILES (no microphone)
-------------------------------------------------------------------------------

  lecnote file lecture.m4a              transcribe an audio file, then notes
  lecnote file clip.mp3 png             ...and render it as a diagram image
  lecnote text transcript.txt notion    notes from a transcript you already have

  Audio formats: wav, mp3, m4a, ogg, flac, webm, mp4.


-------------------------------------------------------------------------------
 REUSING A CAPTURED LECTURE
-------------------------------------------------------------------------------

  lecnote sessions             list captured lectures, numbered
  lecnote redo excalidraw      re-render the MOST RECENT in another format
  lecnote redo png --session 3 ...an older one, by number or name prefix
  lecnote transcript           print the last raw transcript
  lecnote transcript --session 3

  The transcript is cached per session, so `redo` costs one model call and
  does NOT re-transcribe. Capture once, export to every format you want —
  one recording can end up as md + Excalidraw + PNG in the same folder.

  `sessions` shows length, which formats already exist, the subject hint and
  the opening line, so lectures are tellable apart without opening them.


-------------------------------------------------------------------------------
 FLAGS
-------------------------------------------------------------------------------

  -v, --vocab "subnetting, CIDR"   subject hint. Improves both transcription
                                   and note accuracy noticeably. Worth using.
  -d, --device 1                   input device index (see `lecnote devices`)
  -p, --show                       also print the notes to stdout
      --keep                       keep the audio file after processing

  Progress goes to stderr and notes to stdout, so this works:

    lecnote text lecture.txt notion -p > notes.md


-------------------------------------------------------------------------------
 HOUSEKEEPING
-------------------------------------------------------------------------------

  lecnote clean                keep the 3 newest sessions, ask before deleting
  lecnote clean --keep 10      keep more
  lecnote clean --days 30      only delete sessions older than 30 days
  lecnote clean --all          delete every session
  lecnote clean -y             skip the confirmation

  Shows what it will delete and the space freed before touching anything.
  Never deletes a session that is actively recording.

  lecnote devices              list audio inputs
  lecnote doctor               check keys, record, and transcribe it back
  lecnote doctor -s 10         record for 10 seconds instead of 6
  lecnote doctor -d 1          use a specific input device
  lecnote doctor --no-stt      only test the mic, skip transcription

  doctor plays back what speech-to-text actually heard, so you can say
  "mera naam hello hai" and check the Hinglish came through before trusting
  it with a real lecture.


-------------------------------------------------------------------------------
 HOTKEY (RAYCAST)
-------------------------------------------------------------------------------

  Raycast > Extensions > Script Commands > Add Script Directory
  Point it at the raycast/ folder in this repo. Five commands appear:

      Toggle (Notion)       start / stop + copy notes
      Toggle (Excalidraw)   same, as a diagram scene
      Listen (System Audio) same rhythm, records what the Mac is playing
      Toggle Audio Output   capture routing <-> normal sound
      Re-render             a captured lecture in another format
      Sessions              list captured lectures
      Status                recording or idle

  Give "Lecture Notes — Toggle (Notion)" a hotkey, e.g. Option+Cmd+L.
  One press starts recording, the next stops it and copies the notes.
  That single key is the whole tool during a lecture.

  The scripts locate the repo themselves, so nothing needs editing.

  Raycast needs its OWN microphone permission, separate from your terminal's.
  If a run reports silence, allow Raycast under
  System Settings > Privacy & Security > Microphone.

  Raycast starts scripts with a minimal environment, not a login shell, so
  the notes CLI would be unfindable on PATH and unable to locate its login.
  lecnote repairs that itself at startup — Finder, launchd and cron too.


-------------------------------------------------------------------------------
 WHERE THINGS LIVE
-------------------------------------------------------------------------------

  ~/.lecnote/sessions/<timestamp>/     one folder per run
      transcript.txt                   raw speech-to-text
      notes-<mode>.md|.json|.png       the generated notes
      meta.json                        duration, mode, subject hint
  ~/.lecnote/current.json              set only while recording
  ~/.lecnote/last.json                 what `redo` points at

  Sessions live outside the project on purpose — lecture recordings are
  personal data and should not sit in a folder you might commit.

  Audio is deleted after processing unless you pass --keep.


-------------------------------------------------------------------------------
 ENVIRONMENT VARIABLES  (set in .env)
-------------------------------------------------------------------------------

  LECNOTE_BACKEND    auto | api | cli        how to reach Claude (default auto)
  LECNOTE_MODEL      claude-sonnet-5         model for writing notes
  LECNOTE_STT_MODEL  whisper-large-v3        model for transcription
  LECNOTE_STT_LANG   en | hi                 "en" transliterates Hindi into
                                             Latin script, "hi" gives Devanagari
  LECNOTE_NOTIFY     0                       disable notifications


-------------------------------------------------------------------------------
 WHEN SOMETHING GOES WRONG
-------------------------------------------------------------------------------

  "the microphone recorded pure silence"
      System Settings > Privacy & Security > Microphone > enable your terminal
      (or Raycast), then FULLY quit and reopen it. Verify with `lecnote doctor`.

  "credit balance is too low"
      Your Anthropic API balance is empty. A Pro/Max subscription does not fund
      the API. Either add credits, or let the default "auto" backend fall back
      to the claude CLI — which is what it already does.

  "GROQ_API_KEY not set"
      Transcription needs it. Free key at https://console.groq.com/keys

  Notes came out wrong / missed something
      The transcript is saved. Check it with `lecnote transcript` to see whether
      the mic missed it or the model did. If the mic heard it correctly, the fix
      is in lecnote/prompts.py. Then `lecnote redo` — no re-recording needed.

  A run failed partway
      Nothing is lost. The transcript is already on disk, so `lecnote redo`
      picks up from there without re-transcribing.

 TYPICAL LECTURE
-------------------------------------------------------------------------------

  Option+N                     (or: lecnote toggle notion)
  ... lecture happens, you keep writing your own notes ...
  Option+N                     stops; notification when ready
  Cmd+V in Notion

  Then, if a diagram would help:

  lecnote redo png             re-renders the same lecture as a flowchart
  Cmd+V in Notion
